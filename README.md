# drawn-cips
Data and python script for Cosgun &amp; Lane (under review).

CIPS-drawings-SEM.ipynb runs the structural equation model (SEM) reported in the article.

COP-CIPS-SEM data.xlsx is the data used in the SEM.

COP-CIPS codebook.xlsx is the full codebook of drawing elements (most of which are contained in hidden rows) and CIPS scores.
